# Social share image (vula-ai.com link previews)

`../../../vula_site/og-share.png` is the 1200×630 render of `share.html`; the 2400×1260 copy here is
for places that want a 2× image. Copy: **Your business, run from WhatsApp.** /
*Orders, invoices, stock and follow-ups, handled by your AI assistant.* (Option 1, agreed 2026-10-20).

The layout follows the logo set's batch 2 share template: brand green, the horizontal lockup with a
cream badge (the on-dark lockup's badge recoloured; the "v" is a cut-out), the faded mark bottom-right,
Outfit Bold / Regular (SIL OFL, see `Outfit-OFL.txt`).

To change the words: edit `share.html`, then from `vula_dashboard/` run
`node ../docs/brand/social-share/render.mjs` and copy the 1200×630 PNG over `vula_site/og-share.png`.
