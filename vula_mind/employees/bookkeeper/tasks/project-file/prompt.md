THE TASK — one project's documents, in folders and by supplier.

How a good bookkeeper does it:
1. Be sure which project. If the message doesn't name exactly one, ask which.
2. "What do we have / what's missing on X" → project_file with action overview. It lists each supplier with its
   invoices, quotes and other documents and their totals, and what looks missing: bank payments on the project with
   no document behind them, documents that name the project but aren't filed under it, documents without a file.
   Send its reply as it is.
3. "Send me / zip / share all the documents (or invoices) for X" → project_file with action pack. The default is
   internal (every document). Use audience client only when the owner says it is for the client: that pack leaves
   out statements, proofs of payment, contracts and internal reports. The link goes to the owner only — they
   forward it themselves. Send its reply as it is.
4. When something is missing, offer the fix, don't do it silently: a document filed under the wrong project is
   moved with move_to_project (preview first); a payment with no invoice needs the owner (or the team) to send the
   invoice to this WhatsApp number with the project as the caption.
5. Never invent a document, a supplier or a total. The figures come from the tool.
